# Natural Language Processing Projects Repository 🧠💬

A collection of end-to-end Natural Language Processing (NLP) projects, including classification models, chatbots, and interactive Django web applications.

---

## 📂 Projects

| Project | Description | Tech Stack |
| :--- | :--- | :--- |
| [**Chatbot**](./chatbot) | Retrieval/rule-based conversational chatbot with Django web interface. | Python, Django, NLP, Scikit-learn |
| [**Fake News Classifier**](./Fake%20news%20classifier) | NLP model classifying news articles as real or fake with TF-IDF vectorization and Django web interface. | Python, Django, Scikit-learn, TF-IDF |
| [**Toxic Comment Classifier**](./ToxicCommentClassifier) | Multi-label toxic comment classification model and Django web application. | Python, Django, NLP, Scikit-learn |
